# StudyLog

StudyLog は、学習の記録・進捗・計画管理を簡単にできるシンプルな学習管理アプリです。

## 機能

- 学習時間の記録
- 教科ごとの学習履歴の確認
- 学習計画の追加と完了管理
- 今週の時間、目標達成率、連続学習日数のリアルタイム表示
- ブラウザ内での保存（localStorage）

## 使い方

1. プロジェクトを開く
2. ローカルサーバーを起動する
3. ブラウザで表示して利用する

```bash
cd /Users/runamuraoka/learning-management-app
python3 -m http.server 8000
```

次に、ブラウザで https://laughing-disco-vprr59vjjv4qf7gx-8000.app.github.dev/ を開きます。
